# KS Notebook Studio 指示

この動画では、投入された当日ソースの数値・順位・波サイズ・風向きを改変しないこと。
欠落値を推測しないこと。
ランキングの順位を並べ替えないこと。
波周期はナレーション・字幕・説明に使用しないこと。

## ナレーション
20代前半の若い女性アナウンサー。やや高めで明るく爽やか。テンポはやや速めで軽快。滑舌明瞭。硬すぎず、母親っぽくせず、機械的に読まない。

## 構成
1. Opening
2. 今日の全体傾向
3. 今日の波ランキング
4. 最新の台風・うねり
5. 明日の予報
6. 明日の注目候補
7. Ending

ランキング後は必ず
「続いて、最新の台風とうねりの情報です。」
明日の予報前は必ず
「ここからは明日の波予想です。」

## NotebookLM Studio 固定設定
- 動画スタイルは必ず「アニメ」を選択する。
- 動画の長さは「短い」ではなく、長い方を選択する。
- この2項目は毎日の生成時に固定設定として扱う。
